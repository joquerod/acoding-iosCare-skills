# Mermaid Diagram Formatting

Use background colors that contrast well with the text. Avoid light backgrounds with white text (e.g., yellow background with white text is hard to read).

Use darker, saturated colors with explicit text color settings:
- `style NODE fill:#2e7d32,color:#fff` (dark green with white text)
- `style NODE fill:#f9a825,color:#000` (amber with black text)
- `style NODE fill:#1565c0,color:#fff` (dark blue with white text)
- `style NODE fill:#c62828,color:#fff` (dark red with white text)
- `style NODE fill:#6a1b9a,color:#fff` (dark purple with white text)
